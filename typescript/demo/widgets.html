Interactive Widgets

This demo showcases all 10 interactive actors implemented in Phase 1.3:

  • SK8Button - Interactive buttons with visual states (normal, hover, pressed, disabled)
  • SK8CheckBox - Checkboxes with toggle functionality and labels
  • SK8RadioButton - Radio buttons with automatic group behavior
  • SK8Slider - Draggable sliders with value constraints and orientation options
  • SK8EditText - Text input fields with keyboard support and cursor management
  • SK8Label - Static text labels with alignment and styling options
  • SK8Container - Layout containers with multiple layout modes (horizontal, vertical, grid)
  • SK8Panel - Panels with title bars, close buttons, and collapsible content
  • SK8Scroller - Scrollable content areas with draggable scrollbars
  • SK8MenuButton - Dropdown menu buttons with selectable items

Try It Out

  • Click buttons to see visual feedback
  • Toggle checkboxes and radio buttons
  • Drag sliders to change values
  • Click the edit text field and type
  • Click the menu button to open the dropdown
  • Click the panel's title bar to collapse/expand it
  • Drag scrollbars to scroll content
