About This Demo

This is a working proof-of-concept of SK8 reimplemented in TypeScript. It demonstrates:

  • Prototype-based object system (SK8Object)
  • Actor/Stage rendering architecture
  • Canvas-based graphics (replaces QuickDraw)
  • Event handling (click, mouse events)
  • Property system with getters/setters
  • Live object manipulation

Example Code

// Create a stage const stage = new SK8Stage('sk8-canvas'); // Create a rectangle const rect = new SK8Rectangle(); rect.set('boundsRect', { left: 100, top: 100, right: 300, bottom: 250 }); rect.set('fillColor', 'red'); rect.set('frameColor', 'black'); // Add click handler rect.addHandler('click', function() { this.set('fillColor', 'blue'); stage.render(); }); // Add to stage stage.addActor(rect); stage.render();

What's Missing (vs Original SK8)

This is a minimal proof-of-concept. The original SK8 had:

  • SK8Script language (natural language scripting)
  • QuickTime integration (movies, sound)
  • Visual development environment
  • Project system (save/load)
  • Comprehensive actor library
  • Animation timeline
  • Much more!
