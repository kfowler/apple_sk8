Example Expressions

          

            5 + 3 * 2 → Arithmetic with precedence
          

          

            (5 + 3) * 2 → Parentheses grouping
          

          

            the left of myActor → Natural language property access
          

          

            item 1 of myList → List indexing (1-based)
          

          

            myActor.width → Dot notation
          

          

            -5 + 10 → Unary minus
          

          

            not true → Logical NOT
          

          

            5 < 10 and true → Comparison and logic
          

          

            "hello" & " " & "world" → String concatenation
          

          

            2 ^ 8 → Exponentiation
          

        


        

          
Control Flow Examples

          

            if 5 > 3 then 100 else 200 end → Simple if/else
          

          

            repeat 5 times ... → Repeat N times loop
          

          

            repeat with i from 1 to 5 ... → For loop
          

          

            while x < 100 ... → While loop
          

          

            try ... catch ... → Error handling
          

        


        

          

            
Natural Language Syntax

            

              SK8Script uses natural language constructs like "the X of Y" for intuitive property
              access.
            

          

          

            
Operator Precedence

            

              Properly handles mathematical operator precedence: multiplication and division before
              addition and subtraction.
            

          

          

            
1-Based Indexing

            

              Following SK8's convention, lists and arrays use 1-based indexing for more natural
              human interaction.
            

          

          

            
Comprehensive Operators

            

              Supports arithmetic (+, -, *, /, %, ^), comparison (=, !=, <, >, <=, >=), and logical
              (and, or, not) operators.
