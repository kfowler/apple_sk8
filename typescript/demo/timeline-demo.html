About

This demo showcases the SK8 Timeline Editor - a powerful animation sequencer for creating complex multi-track animations.

Features

✓ Multi-track animation
✓ Keyframe-based timeline
✓ Multiple easing curves
✓ Real-time preview
✓ Export to code
✓ Undo/Redo support

Keyboard Shortcuts

Space: Play/Pause
Left/Right: Step frame
Delete: Delete keyframe
Ctrl+Z: Undo
Ctrl+Shift+Z: Redo

How to Use

1. Add Tracks: Click the buttons above to add animation tracks
2. Add Keyframes: Double-click on the timeline
3. Edit Keyframes: Click to select, drag to move
4. Change Easing: Select a keyframe to edit easing curve
5. Play: Click play button or press Space
