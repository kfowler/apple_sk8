🎨 SK8 UI Actors Complete Demo

Comprehensive showcase of all 8 interactive UI widgets

1. TabPanel

Tabbed panel with switchable content, closeable tabs, and drag-to-reorder support.

Features:

  • Multiple tabs with custom labels
  • Tab switching on click
  • Closeable tabs with X button
  • Horizontal and vertical orientation
  • Drag-to-reorder tabs
  • Events: tabChanged, tabClosed

2. TreeView

Hierarchical tree display with expand/collapse, selection, and lazy loading support.

Features:

  • Hierarchical tree structure
  • Expand/collapse nodes
  • Single and multi-selection modes
  • Lazy loading for large trees
  • Drag-drop to reorder (visual feedback)
  • Events: nodeExpanded, nodeSelected

3. ListView

Scrollable list with columns, sorting, virtual rendering, and selection modes.

Features:

  • Multiple columns with headers
  • Click column headers to sort
  • Virtual rendering for large datasets
  • Single/multi/none selection modes
  • Alternate row colors
  • Events: itemSelected, sortChanged

4. Toolbar

Horizontal toolbar with icon buttons, separators, spacers, and overflow menu.

Features:

  • Icon + text buttons
  • Separators and spacers
  • Overflow menu when too many items
  • Dockable and floating modes
  • Hover effects
  • Events: buttonClicked

5. Dialog

Modal/modeless window with draggable title bar, resizable borders, and custom buttons.

Features:

  • Modal and modeless modes
  • Draggable by title bar
  • Resizable with corner/edge handles
  • Customizable buttons (OK/Cancel/Yes/No)
  • Close button in title bar
  • Z-order management
  • Events: dialogClosed, buttonClicked

6. ColorPicker

Complete color selection widget with HSV wheel, RGB sliders, hex input, and presets.

Features:

  • HSV color wheel for hue/saturation selection
  • RGB sliders for precise adjustment
  • Opacity/alpha slider
  • Hex color code display
  • Preset color swatches
  • Live preview of selected color
  • Events: colorChanged

7. FileDialog

File browser with directory navigation, filters, preview pane, and open/save modes.

Features:

  • File browser interface
  • Directory navigation (up button)
  • File type filters (All/Images/Documents)
  • Preview pane for selected files
  • Open and Save modes
  • File icons (folders vs files)
  • Events: fileSelected, pathChanged

8. StatusBar

Bottom-aligned status bar with segments, icons, progress bars, and tooltips.

Features:

  • Multiple segments (left/center/right aligned)
  • Icon support (emoji or symbols)
  • Integrated progress bars
  • Tooltips on hover
  • Clickable segments
  • Dynamic updates
  • Events: segmentClicked
