# Example 10: Platform Game

## Overview
A complete platformer game with physics, collision detection, enemies, and collectibles.

## Features
- **Player Character:** Keyboard-controlled with physics
- **Jump Mechanics:** Realistic gravity and jumping
- **Platforms:** Multiple levels and obstacles
- **Collectibles:** Coins to collect for points
- **Enemies:** Moving obstacles to avoid
- **Lives System:** 3 lives with respawn
- **Score Tracking:** Points for time and coins
- **Win Condition:** Reach the goal flag

## What You'll Learn
1. Game loop architecture
2. Physics simulation (gravity, velocity)
3. Collision detection (AABB)
4. Keyboard input handling
5. Enemy AI (patrolling)
6. Score and lives management
7. Game state management
