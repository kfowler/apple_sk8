# Example 08: Video Player

## Overview
Custom video player with timeline, controls, playlist, and fullscreen support.

## Planned Features
- **Playback Controls:** Play, pause, seek, volume
- **Timeline:** Visual progress with scrubbing
- **Playlist Management:** Multiple videos in queue
- **Playback Speed:** 0.5x to 2x speed control
- **Fullscreen Mode:** Native fullscreen API
- **Keyboard Shortcuts:** Space (play/pause), arrows (seek), F (fullscreen)
- **Subtitles/Captions:** SRT/VTT support

## What You Would Learn
1. HTML5 Video API integration
2. Custom video controls
3. Timeline/progress visualization
4. Playlist data structures
5. Fullscreen API
6. Keyboard shortcuts
7. Media session API

## Implementation Notes
- `SK8MediaActor` for video display
- Custom UI overlay
- State synchronization with video element
- Time formatting utilities
