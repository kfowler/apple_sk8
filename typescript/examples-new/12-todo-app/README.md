# Example 12: Todo Application

## Overview
Full-featured task management application with priorities, filtering, and persistence.

## Features
- **Add/Edit/Delete:** Full CRUD operations
- **Completion:** Toggle tasks as complete
- **Priorities:** High, medium, low priority levels
- **Filtering:** View all, active, completed, or by priority
- **Persistence:** LocalStorage for data permanence
- **Statistics:** Live count of tasks
- **Keyboard Shortcuts:** Quick navigation
- **Clear Completed:** Bulk action

## What You'll Learn
1. CRUD operations
2. LocalStorage API
3. State management
4. Filtering and sorting
5. Event delegation
6. Keyboard shortcuts
7. Data persistence patterns

## How to Use
- **Add Task:** Type and press Enter
- **Priority:** Add !!! for high, !! for medium
- **Complete:** Click checkbox
- **Delete:** Click delete button
- **Filter:** Use filter buttons
- **Shortcuts:** Ctrl+A (active), Ctrl+C (completed)
