# Example 06: Drawing Application

## Overview
A complete drawing application with multiple tools, color selection, undo/redo, and export functionality.

## Features
- **Tools:** Pen, Line, Rectangle, Circle, Eraser
- **Colors:** 16-color palette
- **Brush Size:** Adjustable 1-20px
- **Undo/Redo:** Full history (Ctrl+Z, Ctrl+Y)
- **Save/Load:** LocalStorage persistence
- **Export:** PNG export

## What You'll Learn
1. Advanced canvas drawing techniques
2. Tool system architecture
3. Undo/redo implementation
4. File export
5. Keyboard shortcuts
6. State management

## How to Run
Open `index.html` in your browser and start drawing!
