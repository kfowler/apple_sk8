01. Hello World

Your first SK8 application! Click the rectangle to change its color.

Try this:

Click the colored rectangle to cycle through different colors.

Each click demonstrates event handling in SK8!

// Create a stage (canvas manager) const stage = new SK8Stage(canvas); // Create a rectangle actor const rect = new SK8Rectangle(); rect.setBoundsRect({ left: 150, top: 100, right: 350, bottom: 200 }); rect.setFillColor({ r: 100, g: 150, b: 255, a: 1 }); // Add click handler rect.addEventListener('click', () => { // Change color on click rect.setFillColor(randomColor()); }); // Add to stage and render stage.addActor(rect); stage.startRendering();
