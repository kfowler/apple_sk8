# SK8 TypeScript Examples Gallery

Welcome to the SK8 TypeScript examples gallery! This collection showcases the power and flexibility of the SK8 multimedia authoring system through practical, real-world examples.

## Quick Start

Each example is self-contained and can be run by opening its `index.html` file in a modern web browser. All examples work offline and include comprehensive documentation.

## Example Categories

### Beginner Examples (01-05)
Perfect for learning SK8 fundamentals. Start here if you're new to SK8.

### Intermediate Examples (06-10)
Build complete applications using multiple SK8 features together.

### Advanced Examples (11-15)
Complex applications demonstrating advanced techniques and patterns.

## Running Examples

### Option 1: Direct File Access
Simply open any `index.html` file in your browser:
```bash
cd examples-new/01-hello-world
open index.html  # macOS
# or
start index.html  # Windows
# or
xdg-open index.html  # Linux
```

### Option 2: Local Server (Recommended)
For examples that load external resources:
```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx http-server

# Then open: http://localhost:8000/examples-new/
```

### Option 3: Live Demos
Visit the live demo gallery at: https://[your-username].github.io/sk8/examples-new/

## Learning Path

### Complete Beginner
1. Start with **01-hello-world** to understand the basics
2. Move to **02-interactive-shapes** to learn about multiple actors
3. Try **03-animation-basics** for motion and effects
4. Complete **04-ui-components** to build interfaces
5. Finally, **05-sk8script-intro** to learn scripting

### Some Programming Experience
1. Quick review of **01-hello-world** and **02-interactive-shapes**
2. Deep dive into **06-drawing-app** as your first project
3. Choose examples based on your interests (games, multimedia, apps)

### Experienced Developer
1. Browse the examples that match your project goals
2. Study the advanced examples (**11-15**) for patterns
3. Use templates to start your own projects
