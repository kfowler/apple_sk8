# Example 05: SK8Script Introduction

## Overview
Learn SK8Script, the built-in scripting language that makes SK8 accessible to non-programmers.

## What You'll Learn
1. SK8Script syntax and grammar
2. Variables and expressions
3. Control flow (if, repeat)
4. Built-in functions
5. Actor manipulation via script

## SK8Script Basics

### Variables
```
set x to 100
set name to "Hello"
set result to x * 2
```

### Control Flow
```
if x > 50 then
  print "Large"
else
  print "Small"
end if

repeat 5 times
  print "Loop"
end repeat
```

### Functions
```
sqrt(16)          -- Returns 4
random(1, 100)    -- Random number
length("hello")   -- Returns 5
```

## How to Run
Open `index.html` and experiment with the script editor!
