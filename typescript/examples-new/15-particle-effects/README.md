# Example 15: Particle Effects

## Overview
Showcase of various particle system effects with configurable parameters and real-time performance metrics.

## Features
- **Fireworks:** Explosive burst effect with gravity
- **Snow:** Gentle falling with drift
- **Rain:** Fast diagonal precipitation
- **Fire:** Rising flames with turbulence
- **Stars:** Twinkling starfield

## What You'll Learn
1. Particle system architecture
2. Object pooling for performance
3. Physics simulation (gravity, velocity)
4. Performance optimization
5. Real-time parameter tuning
6. Visual effects techniques
7. FPS monitoring

## Configuration
- **Particle Count:** 10-500 particles
- **Speed:** 0.1x to 3x multiplier
- **Size:** 1-10 pixels

## Implementation Details
- Object-oriented particle class
- Efficient array filtering
- Canvas fade trails
- Color palettes per effect
- Life-based alpha fading

## Code Statistics
- **Lines:** ~700
- **Time:** 2-3 hours
- **Difficulty:** Advanced

## Challenges
- Add particle collision
- Create explosion shockwaves
- Implement smoke trails
- Add wind effects
- Create custom particle shapes
- Add particle emitters

## Performance Tips
- Use object pooling for particles
- Limit particle count
- Use requestAnimationFrame
- Minimize canvas operations
- Cache calculations
